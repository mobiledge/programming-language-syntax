# Structs — JavaScript

[Docs](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Object_initializer)

```javascript
// JavaScript has no structs; plain objects
// serve the same role
const point = { x: 3, y: 4 };
console.log(point.x); // 3

// Non-destructive update via spread
const point2 = { ...point, x: 10 };
```
